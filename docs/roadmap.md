# Roadmap

## Phase 1: Evidence inventory

- Create products and suppliers
- Upload documents
- Add document type, issue date, and expiry date
- Show missing and expiring evidence
- Export a basic evidence pack

## Phase 2: Review workflow

- OCR document metadata
- Allow users to confirm or correct extraction
- Add reviewer assignment and approval states
- Add an immutable audit trail

## Phase 3: Business integrations

- Email and cloud-drive ingestion
- Scheduled renewal reminders
- Customer and auditor sharing links
- Optional AI summaries with source citations
